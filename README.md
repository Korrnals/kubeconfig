# Утилита kubeconfig

Назначение утилиты - формировать общий `./kube/config` файл, из различных одиночных вариаций

## Этапы разработки

1. Реализовать структуру утилиты, в которой будет реализован базовый функционал:
   - Структуры - для хранения данных;
   - флаги и конфигурация через файл или переменные окружения;
   - MVP

2. Определить источники данных (файлы, STDIN, конфигурация, сервисы)
3. Оптимизация хранения - реализация SQLite (в базе данных)
4. интеграция различных сервисов (vault, consul, api)
