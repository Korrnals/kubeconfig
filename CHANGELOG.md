# CHANGELOG

## [v1.0.0] — 2025-12-09 — **MVP**

### Первая стабильная версия — **утилита формирования единого kubeconfig'a**

### Особенности

- **Полный merge** всех kubeconfig-файлов из директории (`--dir`, `-d`)
- **Умное переименование** `kubernetes-admin` → `kubernetes-admin@<current-context>`  
  → Решает самую болезненную проблему kubeadm: дублирование пользователей
- **Сохранение всех сертификатов** — ни один не теряется
- **Красивый вывод** с правильными отступами (как `kubectl config view`)
- **Флаг `--output`, `-o`** — сохраняет результат в любой файл, включая `~/.kube/config`
- **Флаг `--list`, `-l`** — показывает все кластеры и контексты (работает даже без `--dir` — берёт из `~/.kube/config`)
- **Флаг `--version`, `-v`** — информация о версии
- **Автоматическое создание** директории `.kube` при сохранении
- **Расширение `~`** в путях (`~/.kube/config`)
- **Проверка содержимого** — пропускает невалидные файлы, не падая
- **Чистая, модульная архитектура**:
  - `internal/models/config` — структуры
  - `internal/cli` — CLI-логика
  - `internal/utils` — вспомогательные функции
- **Идиоматичный Go** — указатели, конструкторы, пакеты, ошибки

### Почему это лучше, чем всё остальное

| Инструмент     | Решает проблему `kubernetes-admin`? | Сохраняет все сертификаты? | Простота | Работает с `~` |
|----------------|--------------------------------------|----------------------------|---------|---------------|
| `kubectl`      | Нет                                  | Нет                        | ★★★★    | Да            |
| `kubecm merge` | Нет                                  | Нет                        | ★★★     | Да            |
| `kubie`        | Частично                             | Да                         | ★★      | Да            |
| **Твой инструмент** | **Да**                           | **Да**                     | **★★★★★** | **Да**        |

### Будущее

- `--current-context` — показать текущий
- `--rename-context` — переименовать
- Поддержка `$KUBECONFIG`
